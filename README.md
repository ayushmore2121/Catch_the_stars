# Catch the Falling Stars



\# 🌟 Catch the Falling Stars

![Visitor Count](https://visitor-badge.laobi.icu/badge?page_id=ayushmore2121.Catch_the_stars)



A feature-rich, arcade-style 2D browser game built with \*\*HTML5 Canvas\*\*, \*\*CSS3\*\*, and pure \*\*JavaScript\*\*, featuring neon visuals, particle effects, web audio synthesizer sound effects, power-ups, and combo tracking!



🎮 \*\*\[Play Live Demo](https://ayushmore2121.github.io/Catch\_the\_stars/)\*\* \*(Make sure GitHub Pages is enabled in your repo settings!)\*



\---



\## 🚀 Features



\- \*\*Neon Arcade Aesthetics:\*\* Clean dark-mode UI with a radial-gradient background and glowing canvas elements.

\- \*\*Dynamic Entities \& Hazards:\*\*

&#x20; - ⭐ \*\*Golden Stars:\*\* Standard catchable items (+100 pts).

&#x20; - 🔵 \*\*Blue Stars:\*\* Fast-moving high-value items (+250 pts).

&#x20; - 💣 \*\*Red Asteroids:\*\* Hazardous obstacles that drain your shields.

\- \*\*Power-Up System:\*\* Collect temporary cosmic power-ups:

&#x20; - 🟣 \*\*WIDE:\*\* Temporarily broadens your basket.

&#x20; - 🟢 \*\*MAGNET:\*\* Pulls nearby stars toward your basket.

&#x20; - 🟡 \*\*SLOW:\*\* Slows down falling items for easier navigation.

\- \*\*Audio Synthesizer:\*\* Built using the native \*\*Web Audio API\*\*—no external audio files or downloads required!

\- \*\*Combos \& High Scores:\*\* Chain catches to increase your score multiplier and track your high score using `localStorage`.

\- \*\*Flexible Controls:\*\* Fully responsive support for \*\*Keyboard (Arrow Keys / A \& D)\*\*, \*\*Mouse\*\*, and \*\*Touch drag\*\*.



\---



\## 🕹️ How to Play



1\. Move your basket left and right to catch falling items.

2\. Avoid the red asteroids (`💣`), as they cost you a life/shield.

3\. Catch power-ups (`WIDE`, `MAGNET`, `SLOW`) to gain special advantages.

4\. Try to beat your highest score!



\---



\## 🛠️ Built With



\* \*\*HTML5 Canvas\*\* - Rendering engine

\* \*\*CSS3\*\* - UI overlay styling \& animations

\* \*\*JavaScript (ES6+)\*\* - Game loop, physics, collision detection, and state management

\* \*\*Web Audio API\*\* - Procedural sound effects
